🧪 Keycloak Error Redirect Tester

⚠️ Important: Replace YOUR_KEYCLOAK_LOGIN_URL below with your actual Keycloak login URL.

1. Test URL-Based Errors

Click these links to test different error scenarios:

Test cancelledOnApp Test access_denied Test invalid_request Test server_error

2. Manual URL Testing

Copy and paste this URL template, replacing the placeholder:

http://localhost:8080/realms/master/protocol/openid-connect/auth?error=cancelledOnApp&error_description=User%20cancelled%20authentication

3. Debug Console Testing

With debug mode enabled, open browser console (F12) and look for:

  • [ErrorRedirect] URL-based error detected: cancelledOnApp
  • [ErrorRedirect] Redirecting to: https://app.valura.co.in/auth?...

4. Expected Redirect

When errors are detected, you should be redirected to:

https://app.valura.co.in/auth?error_code=CANCELLED_ON_APP&error_message=Authentication%20was%20cancelled%20in%20the%20mobile%20app&...

5. Real Error Testing

  1. Go to your normal Keycloak login page
  2. Enter wrong username/password
  3. Submit form
  4. Should redirect when error appears
